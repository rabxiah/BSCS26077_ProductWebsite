# BSCS26077_ProductWebsite
This project is a simple and attractive coffee shop website created using HTML
and CSS. The website is designed to provide customers with information about the coffee shop, its products, and services.
The website includes different sections such as the Home page, Products and Contact Us.
It uses images, text, buttons, and CSS styling to create a clean and user-friendly design.
Technologies Used:
     - HTML
     - CSS
Features:
     Attractive coffee shop homepage
     Coffee and food products section
     Contact Us section
     Images and styled content
     Simple and user-friendly layout
